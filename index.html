04 · Hydrology

Watershed Delineation & Sub-Watershed Prioritization

Delineated the Doodhganga Basin watershed from an SRTM 30 m DEM in ArcMap 10.8.2 and prioritized its sub-watersheds using linear, areal and relief morphometric parameters to support soil and water conservation planning.

DEM→Fill→Flow Direction→Flow Accumulation→Streams →Pour Points→Sub-Watersheds→Morphometric Analysis→Priority Map
Data
SRTM 30 m Digital Elevation Model; drainage network and watershed boundary
Tools
ArcMap 10.8.2, Spatial Analyst
Method
Linear parameters (stream length, bifurcation ratio, drainage density), areal parameters (drainage texture, form factor, circularity ratio) and relief parameters (basin relief, relief ratio) computed per sub-watershed and combined into a compound parameter to rank priority as High, Medium or Low
Output
Sub-watershed-wise priority map of the Doodhganga Basin and a morphometric parameter table
ArcMap 10.8SRTM DEMMorphometric Analysis

05 · Drought Monitoring

GIS-Based Drought Monitoring Tool

A custom ArcGIS Pro script tool ("DroughtMetrics") built with ArcPy that automates drought assessment by calculating vegetation and temperature indices directly from Landsat satellite bands.

Red / NIR / Green Bands→Optional Clip→NDVI · NDWI · NDMI→VCI · VHI→Optional TCI (needs LST)
Data
Landsat 8 Collection 2 Level-2 imagery (Red, NIR, Green, and optional LST bands), optional clip shapefile
Tools
ArcGIS Pro, ArcPy, Spatial Analyst extension
Parameters
Red Band, NIR Band, Green Band (required); LST Band and Clip Shapefile (optional); Output Folder
Outputs
NDVI, NDWI, NDMI, VCI, VHI rasters, plus TCI when an LST band is supplied
import arcpy
from arcpy.sa import *

red_band = arcpy.GetParameterAsText(0)   # Red band (required)
nir_band = arcpy.GetParameterAsText(1)   # NIR band (required)
green_band = arcpy.GetParameterAsText(2) # Green band (required)
lst_band = arcpy.GetParameterAsText(3)   # LST band (optional)
clip_shapefile = arcpy.GetParameterAsText(4)
output_folder = arcpy.GetParameterAsText(5)

arcpy.CheckOutExtension("Spatial")

def clip_raster(raster):
    if clip_shapefile:
        return ExtractByMask(Raster(raster), clip_shapefile)
    return Raster(raster)

red_band = clip_raster(red_band)
nir_band = clip_raster(nir_band)
green_band = clip_raster(green_band)

ndvi = (nir_band - red_band) / (nir_band + red_band)
ndvi.save(output_folder + "/NDVI.tif")

ndwi = (green_band - nir_band) / (green_band + nir_band)
ndwi.save(output_folder + "/NDWI.tif")

Drone DEM Generation

Generated a Digital Elevation Model from drone-captured imagery by aligning photos into a sparse point cloud, densifying it, and interpolating a DEM surface.

Produce a DEM raster from a UAV photo set
Tools
Agisoft Metashape Professional

02 · DSM & DTM Generation

DSM & DTM Generation

Derived both a Digital Surface Model (all above-ground features) and a Digital Terrain Model (bare-earth surface) from the same UAV dataset by classifying and filtering dense-cloud points.

Objective
Separate surface and terrain models from one photogrammetric dataset
Tools
Agisoft Metashape Professional
Input
UAV photo set, dense point cloud
Process
Align Photos → Build Dense Cloud → Build Mesh → Classify Ground Points (max angle, max distance, cell size) → Filter By Class → Build DEM restricted to Ground points (DTM) or to all point classes (DSM)
Output
Two DEM rasters: a ground-classified DTM and an all-class DSM
Dense Cloud→Classify Ground Points→Filter by Class→DTM (Ground)/DSM (All Classes)

09 — Knowledge Hub

How GIS and Remote Sensing actually work.

A working reference to the concepts behind the projects above — not a textbook, a quick way to see how I think about spatial data.

The electromagnetic spectrum bands a sensor records determine what it can "see" on the ground.

Visible Near Infrared Shortwave IR Thermal IR Microwave

Visible and near-infrared bands drive most vegetation and land-cover work; thermal and microwave bands support temperature and all-weather / radar-based analysis (e.g. Sentinel‑1, ALOS PALSAR).

Every surface reflects light differently across bands — that reflectance curve is its spectral signature.

Vegetation Water Soil Built-up
